# viral-playbook

Скилл для Claude Code: как придумать, написать, смонтировать и разобрать контент, который досматривают, сохраняют, комментируют и пересылают. Рилсы, шортсы, TikTok, YouTube, карусели, посты, треды, рассылки.

## Установка

Скопируйте папку в `~/.claude/skills/viral-playbook/` и перезапустите Claude Code. Вызов: `/viral-playbook` или просто задача вроде «напиши 10 хуков для рилса про…».

## Первый запуск

Скилл попросит заполнить карточку проекта: аудитория, боли, обещания, запреты. Карточка сохранится в `references/project-cards.md`, дальше скилл будет работать без вопросов.

## Что внутри

| Файл | О чём |
|---|---|
| `SKILL.md` | Процедура: идеи, сценарий, монтаж, разбор, адаптация, серии |
| `PLAYBOOK.md` | Анатомия контента: дистрибуция, психология, хуки, удержание, триггеры, форматы, сценарии, метрики, чеклисты |
| `references/editing.md` | Монтаж снятого видео: съёмка, склейки, хук-монтаж, перебивки, субтитры, звук, цвет, экспорт, рецепты ffmpeg |
| `references/video-production.md` | Ролики без лица: запись экрана, моушн-графика, озвучка, звук |
| `references/video-tools.md` | Инструменты со ссылками и лицензиями |
| `references/project-cards.md` | Шаблон карточки проекта и пример |

Цифры в плейбуке — рабочие ориентиры, а не правила площадок. Сверяйте их с медианой своего аккаунта.
