# Инструменты для видео

Подборка для рилсов, шортсов и роликов о продукте. Лицензии указаны на момент составления (ноябрь 2026) — перед коммерческим использованием проверяйте актуальные. Перед установкой любого репозитория читайте его код и установщик: подборки в духе «awesome-list» не гарантируют безопасность.

Порядок работы: структура и хук (PLAYBOOK) → съёмка или анимация → монтаж (`editing.md`) → звук → проверка → публикация.

## Монтажные программы (снятое видео)

| Инструмент | Для чего | Цена / лицензия | Учесть |
|---|---|---|---|
| CapCut (десктоп и телефон) | Быстрый монтаж рилсов: авто-субтитры, шаблоны, эффекты, удаление пауз | Бесплатно + платная подписка | Прочитайте условия использования контента и шаблонов для коммерческих аккаунтов |
| Edits (Instagram) | Монтаж на телефоне под Reels, без водяных знаков | Бесплатно | Привязан к экосистеме Instagram |
| DaVinci Resolve | Профессиональный монтаж, цветокоррекция, звук (Fairlight) | Бесплатная версия покрывает почти всё; Studio платная | Требователен к железу |
| Adobe Premiere Pro | Индустриальный стандарт, авто-субтитры, удаление пауз по тексту | Подписка | — |
| Final Cut Pro | Быстрый монтаж на Mac | Разовая покупка | Только macOS |
| Descript | Монтаж «по тексту»: правишь расшифровку — режется видео; удаление слов-паразитов | Бесплатно + подписка | Видео загружается в облако |

## Разбор и проверка

| Инструмент | Для чего |
|---|---|
| `ffmpeg -vf freezedetect` | Найти «мёртвые» участки без движения (PLAYBOOK §14.5) |
| `ffmpeg -vf "fps=2,scale=270:480,tile=8x6"` | Лист кадров для быстрой проверки глазами |
| `ffmpeg -af ebur128` | Замер громкости готового MP4 |
| whisper | Сверить озвучку или субтитры со сценарием |
